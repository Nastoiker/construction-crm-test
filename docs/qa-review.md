# Senior QA review

Проведено отдельным проходом автором реализации. Это воспроизводимые автоматические проверки и визуальный просмотр, а не независимая сертификация. Дата: 03.11.2026.

## Проверенное покрытие

| Уровень                         | Покрытие                                                                                                                                        |
| ------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| PostgreSQL / PGlite             | 60 тестов: RLS, роли, 50 переходов, создание, переназначение, удаление, сохранность истории, конфликт версий, валидация                         |
| Unit / Vitest                   | 3 теста доступных действий интерфейса                                                                                                           |
| Playwright / настоящий Supabase | 7 сценариев: вход, полный жизненный цикл, две разные учётки исполнителей, API-атаки, мобильный экран, сетевой сбой, конкурентное изменение, axe |
| Статический анализ              | TypeScript strict, ESLint hooks / a11y / FSD, Prettier                                                                                          |
| Визуально                       | Экран входа, список объектов, карточка задачи, мобильная ширина 390 px                                                                          |

Полный браузерный сценарий создаёт объект и задачу, проверяет недоступность для второго исполнителя, проходит «новая → работа → проверка → доработка → работа → проверка → принята», проверяет семь событий истории, редактирует и переназначает задачу, проверяет потерю/получение доступа, отменяет и подтверждает удаление, редактирует и удаляет объект.

## Найдено и исправлено

- Недостаточный контраст вторичного текста. Цвета скорректированы; axe WCAG A/AA не находит нарушений на трёх проверенных экранах.
- Слишком долгое ожидание после сетевого сбоя из-за двух слоёв retry. Убраны повторы PostgREST; проверены сообщение и успешное восстановление кнопкой «Повторить».
- Node 22.17 ломал загрузку ESM-зависимостей тестового раннера. На актуальном патче Node 22 сценарии проходят; минимальная версия закреплена в `engines` и README.
- После визуального уточнения весь набор Playwright повторно пройден: редизайн не изменил бизнес-сценарии.

## Практические границы

Автоматизирован браузер Chromium; Firefox и WebKit не запускались. Мобильная проверка — эмуляция viewport, не физический телефон. Нагрузочное тестирование и пентест не выполнялись. Проверки SQL на PGlite дополняются реальными HTTP-запросами к Supabase; они не выдаются за тестирование всей инфраструктуры PostgreSQL.

Команды воспроизведения — в README. При падении Playwright сохраняет screenshot, trace и HTML-отчёт. Секреты и локальные пароли не включаются в сдачу репозитория.

# Senior developer review

Проведено как отдельный проход ревью автором реализации, без заявления о независимом внешнем аудите. Дата: 03.11.2026.

| Приоритет | Проверка / находка                                    | Результат                                                                                                          |
| --------- | ----------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| P0        | Исполнитель может обойти UI и прочитать чужую задачу  | Закрыто RLS, подтверждено PostgreSQL-тестами и прямыми запросами к Supabase API                                    |
| P0        | Подмена роли / автора / истории прямым запросом       | У API-ролей отозваны права записи; роль задаётся администратором; RPC выводит автора из `auth.uid()`               |
| P0        | Неверный переход / возврат без комментария            | Матрица проверяется в БД; 50 сочетаний роли/статусов покрыты тестами                                               |
| P1        | Повторная отправка и устаревшая версия                | `FOR UPDATE`, версия записи, одна транзакция с историей; ошибка конфликта и обновление экрана проверены Playwright |
| P1        | Неявный PUBLIC EXECUTE у security-definer функций     | Явно отозван; доступ разрешён только нужным ролям; `search_path = ''`, полные имена объектов                       |
| P1        | Потеря истории при удалении                           | Логическое удаление, без каскадного уничтожения истории; проверено SQL-тестом                                      |
| P1        | Секретный ключ в сборке                               | Только публичные VITE-параметры; seed отдельно, env исключён из Git и Docker-контекста; добавлен сканер            |
| P1        | Двойные сетевые повторы затягивали loading            | Исправлено: повторами управляет TanStack Query, автоматический retry PostgREST выключен                            |
| P1        | Фоновое обновление сбрасывало открытый черновик формы | Исправлено: ключ формы зависит от ID, а не версии записи                                                           |
| P1        | CD мог проверить один commit, а собрать другой        | Исправлено: reusable CI и checkout деплоя получают один SHA                                                        |
| P2        | Строковые имена RPC и неограниченные параметры        | Исправлено: сгенерированные типы Supabase, generic RPC по типам функций                                            |
| P2        | Весь JavaScript одним большим файлом                  | Разделены React, Supabase и формы; сборка не предупреждает о чанках >500 КБ                                        |

**Оставшиеся ограничения:** список до 1000 записей, без realtime, без многокомпанейной изоляции, логируется только история статусов. Они перечислены в решениях. Ошибки сборки или тестов не скрываются.

`npm audit --omit=dev` не обнаруживает уязвимостей. Полный audit сообщает 13 moderate в инструментах линтинга и транзитивном `minimatch`; совместимый набор ESLint 9 выбран из-за peer-зависимости `eslint-plugin-jsx-a11y`. Принудительная несовместимая замена зависимостей не выполнялась. Ранее найденные critical в старом Vitest устранены обновлением.
